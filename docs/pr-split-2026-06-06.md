## PR1 — chore(db)!: consolidate migrations into an idempotent bootstrap

**Why:** the per-migration pipeline + the legacy data-ETL are replaced by a single
idempotent schema bootstrap (Founder decision: "bootstrap = sole source"). The
bootstrap is built from a `pg_dump`/`SHOW CREATE` of the verified-healthy DBs, so
it matches reality exactly — and bakes in three security fixes the old schema
carried: the **mig-32 `security_invoker` cross-tenant view leak**, **RLS on
`subject_erasure_request`** (conformance C3), and **`REVOKE EXECUTE` on the PII
purge function** (this is audit **P0 #1**).

**Changes**
- **New:** `infra/bootstrap/{bootstrap-pg,bootstrap-ch,bootstrap-pg-ai,remediate-existing-dbs}.sql`, `scripts/bootstrap-db.sh`.
- **Rewired:** `docker-compose.yml` (initdb auto-applies bootstrap), `Makefile` (`make bootstrap`), `README.md`, `scripts/dev-up.sh`, `tests/integration/db-integration/run.sh` (applies bootstrap).
- **Conformance repointed → bootstrap:** `check_clickhouse.py`, `check_decision_log.py`, `check_memory.py`, `check_money_types.py`, `check_rls.py` (C3 globs + C12 mis-grant rewrite), `check_fact_schema_drift.py` (table-scoped), `test_status_gated_purge.py`, `conformance.yaml`, `docs/schema/canonical-facts.yaml` (reconciled to true schema: +`raw_event_id`/`provenance`, −5 stale PG-store entries).
- **CI:** `.github/workflows/ci.yml` — remove `migrator` + `parity-gate` jobs (coupled to deleted ETL).
- **Deleted:** `tools/migrate-legacy/`, `apps/core-service/migrations/local-dev/`, `apps/analytics-service/migrations/clickhouse/`, `apps/intelligence-service/migrations/postgres/`, `scripts/migrate.sh`, `scripts/seed-local-{realtime,metric-engine}.sh`, `tests/integration/{migrator,parity}/`. **Kept:** `migrations/manual/` (live-cutover runbooks) + `docker/initdb-dev/` (test role fixtures).

**Validation:** fresh-DB bootstrap applies clean (45 tables, counts match live); CH idempotent; conformance **11 PASS / 0 FAIL** (C3 now passes); drift gate clean; purge test 25/25; tenancy harnesses 11/0 + 7/0.

**Risk:** highest blast radius (deletes migration history, rewrites the C1–C14 gates). Reversible via git. Review first.

**Follow-ups:** the live Supabase + running `brain_dev` need `remediate-existing-dbs.sql` applied (Founder/console). `parity-gate` to be re-authored on a bootstrap seed.
